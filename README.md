**RECALL is a persistent memory engine for AI coding agents.** It preserves project knowledge, decisions, and developer instructions across sessions, making relevant context available to agents through the **Model Context Protocol (MCP)**.

- Persistent project memory, retrieval, and context assembly.
- Custom-instruction precedence, conflict handling, and memory lineage.
- MCP integration, API, and a separate web dashboard.

**My contributions:** system architecture, database design, memory orchestration, instruction precedence, context assembly, and integration testing. RECALL was developed collaboratively for **Agentia '26 — Software Track** and continues in active development.

**Stack:** Python · MCP · FastAPI · SQLite · ChromaDB · React · Tailwind CSS  
**Planned:** PostgreSQL · pgvector
